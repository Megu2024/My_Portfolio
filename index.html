Projects

"Real-Time RFID-Based Inventory Tracking System for Jewellery"


This project focuses on developing a smart RFID-based inventory tracking system for jewellery management using the ESP8266 microcontroller and RC522 RFID reader. Each jewellery item is tagged with a unique RFID tag, enabling contactless identification and automated inventory updates. The system continuously scans items in the showcase and displays real-time inventory details such as item ID, status (present, sold, or missing), and scan time on a web-based dashboard hosted by the ESP8266. If an item is removed without being marked as sold, the system instantly triggers an alert, improving theft detection and inventory accuracy. By integrating RFID technology with IoT-based monitoring, this solution reduces manual effort, enhances security, and provides an efficient and cost-effective approach for real-time jewellery inventory management.

"Rock vs Mine Prediction — Sonar Signal Classification"


This project focuses on developing a machine learning based system to classify sonar signals as either rock or mine for underwater object detection. The model was trained using a sonar signal dataset containing multiple numerical features representing reflected sonar signals from different underwater objects. Various data preprocessing techniques such as normalization and feature handling were performed to improve model performance and stability. Multiple classification algorithms were explored and evaluated to accurately distinguish hazardous objects from normal underwater surfaces. The system demonstrates the practical application of machine learning techniques in signal classification problems and highlights how data-driven models can support underwater threat detection and maritime safety.



"Smart Task Manager — Web Application"


The Smart Task Manager is a web based productivity application developed to help users organize and manage their daily activities efficiently. The system allows users to create tasks, track their progress, and mark them as completed using interactive checkboxes. The application was designed using HTML, CSS, and JavaScript to provide a clean, responsive, and user friendly interface. The project was deployed using GitHub Pages, allowing the application to be publicly accessible through a web browser. This project demonstrates practical front-end web development skills and the implementation of interactive user interface features.
